I build end-to-end automation — the kind where nobody opens a dashboard anymore. Most of it joins three things that usually live apart: LLM APIs, external platforms, and internal CRM data.

### Projects

**[mediation_chat](https://github.com/Dinogrest1/mediation_chat)** — temporary, single-use AI chat sessions with device-bound access links. Only token hashes are stored, TTL is re-checked server-side on every message.

**[profile_analyzer](https://github.com/Dinogrest1/profile_analyzer)** — documents in, report out. Parses PDF, DOCX, PPTX and XLSX with OCR fallback, analyses via LLM, renders a branded Word document from a template.

**Ad analytics loop** *(internal)* — n8n pulls Meta Ads insights daily, joins leads against CRM outcomes in SQL, and hands a pre-triaged digest to Gemini for a structured verdict with reasoning.

**ComfyUI creative toolkit** *(internal)* — self-hosted creative production on open-weight models, packaged as parameterised templates so marketers generate assets without touching a node editor.
